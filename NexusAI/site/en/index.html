Free plugin for Moodle

The AI assistant that answers from your course material.

NexusAI lives inside the Moodle course. It answers from the notes the teacher uploaded, cites where every answer comes from and, when something isn't in the material, says so instead of making it up.

For teachers

Unanswered questions

Why it's different

An AI you can verify.

  • Cites the source

    Every answer says which course document it comes from, so it can be checked.

  • Doesn't make things up

    If the answer isn't in the material, it says so. An honest “I don't know” beats a wrong answer.

  • Teachers find out

    Whatever the material doesn't cover is recorded so the teacher can fill the gap.

  • Inside Moodle

    No extra accounts or platforms: it uses the courses, roles and permissions you already have.

  • On your institution's servers

    Material, indexes and history stay on your server. The AI provider key never reaches the browser.

  • Choose your AI provider

    Works with Gemini, OpenAI or any compatible provider. Switch with a configuration variable.

Installation

How to install it on your Moodle.

NexusAI has two parts: the plugin, installed in Moodle, and your own server that searches the material and talks to the AI. It is not a cloud service: each institution runs it on its own infrastructure.

  1. Install the plugin

    Download the .zip from the Moodle Marketplace.

    In Moodle: Site administration → Plugins → Install plugins, upload the file and follow the installer.

  2. Run the server

    Docker starts the API (FastAPI), PostgreSQL with pgvector and Redis.

    The commands and the configuration file are in the installation guide.

  3. Connect them

    In Plugins → Local plugins → NexusAI, fill in the server URL, the API key and the shared secret.

    Purge the caches and turn NexusAI on in each course that will use it: it ships turned off.

  • Moodle 4.5 to 5.3
  • A server with Docker
  • An AI provider API key

FAQ

Frequently asked questions.

How much does it cost?

The plugin and the server are free and open source. The only costs are the AI provider chosen by the institution, billed per use, and the server it runs on.

Which AI models does it use?

Any provider compatible with the OpenAI API. We tested it with Gemini 2.5 Flash and GPT-4o mini. Switching is done with configuration variables, no code changes.

What happens to student data?

Material, indexes and history stay on the institution's servers. To generate each answer, the question and the relevant excerpts of the material are sent to the chosen AI provider. The plugin implements the Moodle Privacy API, so each user's data can be exported or deleted.

Which Moodle versions are supported?

From 4.5 LTS to 5.3. It is tested in continuous integration against several combinations of version and database.

Can teachers control what it answers?

Yes. NexusAI only answers from the material the teacher uploads, and the teacher decides which documents are used in each course.

Who built it?
